# Секретная сортировка · v0.3

[Играть на DEV](https://artem917.github.io/secret-sort-dev/). Авторская HTML5-головоломка на Vite + TypeScript. Существующий GitHub Actions workflow и `base: '/secret-sort-dev/'` сохранены. Реклама, SDK, платежи, валюты, новые уровни и публикация в каталоге Яндекс Игр не подключены.

## Правила

- **10 колонок × 12 мест**, **9 видов × 12 = 108** уникальных фишек. Начальные высоты: `10,11,11,11,11,11,11,11,11,10`. Все занятые клетки скрыты. Пустые места действительно пусты; колонки выровнены снизу.
- Начальную верхнюю `?` раскрывает игрок отдельным нажатием. Через фишки смотреть нельзя.
- Выбор k-й сверху фишки в непрерывной открытой пачке одного вида выбирает ровно верхние k. Первая — одну, пятая — пять. Повторный клик снимает выбор, другой размер меняет его.
- Цель — пустая колонка либо такой же **открытый** верхний вид. Группа целиком должна помещаться до 12. На другой вид, `?` или с переполнением перенос отклоняется с причиной. Направление выбирает игрок; фишки не удаляются и не объединяются автоматически.
- **После успешного переноса из колонки** новая верхняя закрытая фишка источника открывается автоматически. Только одна, без раскрытия всей скрытой пачки. Это работает и при переносе в резерв. Перенос и открытие — **одна операция и один Undo**. Неверный перенос ничего не открывает.
- **Резерв**: четыре независимых места по одной открытой фишке. Группы в него не обрезаются. Возврат на доску — по обычным правилам. Настройка новых партий позволяет играть без резерва; решения проверены для обеих ёмкостей.
- Победа: девять полностью открытых однородных колонок по 12, одна пустая, резерв пуст. Сохраняются все 108 фишек. Таймера поражения нет. «Ходов нет» учитывает раскрытие, перенос из резерва и Undo.

## Управление и сохранения

Мышь, touch, Enter/пробел; стрелки по клеткам, Home/End по колонке; Esc снимает выбор/закрывает окно; U/Ctrl+Z — Undo, H — возможный ход. Мини-тренировка отдельно показывает раскрытие, выбор 1/5 и перенос пяти через реальный движок. Её позиция не становится обычной партией.

На телефоне вся доска, резерв и основные кнопки видны одновременно без прокрутки поля. Проверяемые размеры: **320×568, 360×740, 390×844, 412×915, 768×1024, 1366×768**. Для каждого проверяются bounding boxes всех 120 игровых клеток, четырёх мест резерва и кнопок, обрезание предками и попадание в центр. На самом маленьком размере клетка около 25.6 px; точность на физическом телефоне требует отдельной проверки. Исходные SVG, цвета и оформление панелей сохранены.

Настройки управляют реальным звуком Web Audio и анимациями, учитывается reduced-motion. Пауза, уход в меню и скрытие вкладки сохраняют позицию. F5 возвращает меню с «Продолжить» только для валидной незавершённой партии.

Схема партии: **`secret-sort:game:v2`**. В переносе сохраняется `autoRevealedId`; Undo сначала восстанавливает скрытость, затем возвращает фишки. История ограничена 80 операциями. Счётчики переносов, отмен и подсказок накопительные. Загрузка проверяет инвентарь, типы, ID, вместимость, открытость, обратную историю и результат.

Корректный `secret-sort:game:v1` мигрирует с точным сохранением доски и старой истории, без удаления backup. Новые действия используют автопоказ; старый Undo сохраняет прежний смысл. **Новые генерации того же текста seed используют v3**, поэтому «Заново» для продолженной партии v0.2 предупреждает о замене раскладки. Старые локальные рекорды сохраняются. При отказе storage игра доступна в текущей вкладке с предупреждением.

## Генерация и сложность

`ordered-donor-v1` заменён на **`reverse-packets-v3`**: 32 структурно различных проверенных обратных конструкции, затем детерминированный выбор шаблона, перестановка видов и колонок одинаковой высоты. Все десять колонок смешанные: минимум пять видов в каждой, максимальная одинаковая серия — три. Непроверенного shuffle и почти готового fallback нет.

Обычная новая партия получает случайный текст seed. Любая строка до 64 символов воспроизводится в текущей версии алгоритма; `?seed=mixed-v3-4` позволяет повторить конкретную партию. `onboarding` не используется по умолчанию и тоже не создаёт почти готовую доску. Перед допуском партии сертификат полностью проигрывается реальными правилами с проверкой инвентаря после каждого действия.

Тесты проверяют **1 000 различных seed, 2 000 полных replay** с резервом 0/4, все 32 обратные конструкции и их структурное отличие. [Доказательство и ограничения генерации](docs/GENERATION.md), [измеримое сравнение old/new](docs/DIFFICULTY.md).

Сертификат знает будущие виды и доказывает существование решения старта. Он не доказывает оптимальность, человеческий интерес, честную сложность или решаемость после произвольных действий. Корпус конечный. В проверенных путях остаются короткие серии одиночных переносов; заключительного перелистывания однородных скрытых стопок нет. Подсказка работает только с видимой информацией.

## Очки и монетизация

При реальной победе один раз фиксируется `max(0,10000 − 30×переносы − 250×отмены − 500×подсказки)`. Раскрытие не даёт очков, Undo не уменьшает стоимость переносов. Подсказка бесплатна и называется «Возможный ход», без обещания оптимальности. Локально сохраняются лучший счёт, минимум переносов, seed, версия генератора и число побед. Это не общесетевой leaderboard и не защищённое от редактирования хранилище.

`AdRewardProvider` остаётся только будущим контрактом: `available:false`, `rewarded:false`, UI его не вызывает. Реальных функций монетизации: **0**.

## Проверки и разработка

Node.js 24 (от 24.13), npm:

```sh
npm ci
npm run typecheck
npm test
npm run compare:difficulty
npm run build
npm run preview
```

Dev: `npm run dev`, `http://127.0.0.1:5173/secret-sort-dev/`. Preview: `http://127.0.0.1:4173/secret-sort-dev/`. На Windows перед повторным `npm ci` остановите собственный Vite preview: он держит DLL rolldown.

58 тестов: правила, атомарный Undo, сохранения/миграция, инвентарь, очки, 2 000 сертификатов и 12 партий стратегии по открытой информации. Существующий workflow не менялся: push в main выполняет npm ci, typecheck/build и GitHub Pages deploy. Unit-тесты запускаются отдельно перед push.

Браузерные проверки:

```sh
npx --yes --package @playwright/cli -- playwright-cli -s=secret-sort-qa open "http://127.0.0.1:4173/secret-sort-dev/?qa=1"
npx --yes --package @playwright/cli -- playwright-cli -s=secret-sort-qa run-code --filename=tests/browser-geometry.js
npx --yes --package @playwright/cli -- playwright-cli -s=secret-sort-qa run-code --filename=tests/browser-smoke.js
```

`browser-geometry.js` проверяет шесть размеров и состояния ошибки/выбора/переноса/Undo. `browser-smoke.js` проводит три настоящие UI-партии на seed `mixed-v3-0`, `mixed-v3-4`, `mixed-v3-11` мышью/клавиатурой и touch. Стратегия видит только открытые виды, размеры и занятость резерва; нет ID, seed или сертификата на входе. Каждый ход выполняется через клик/тап; проверены F5, одиночный атомарный Undo, выбор пяти, резерв, победа, записи рекордов и рестарт. Сертификат читается только после победы для сравнения траекторий.

При `?qa=1` доступны только чтение `window.__secretSort.snapshot()`, `.certificate()` и **замаскированное** `.visible()`. В обычном режиме глобальный объект не создаётся. Скрипт видимой стратегии лежит в `tests/support` и не входит в игру.

Артефакты и скриншоты создаются в `output/playwright/`; `npm run verify:pages` сравнивает опубликованные файлы с локальной сборкой побайтово. Физические Android/iOS и Safari не проверены.

## Модули

`src/game` — правила, инвентарь, история, storage, очки и ad hook; `src/generator` — обратные конструкции и verifier; `src/ui` — DOM/ввод/геометрия и отдельная тренировка; `src/main.ts` — связывание. Оригинальные SVG и фон в `public/` не менялись. Frozen fixture `tests/fixtures/v02` содержит точные исходники baseline `e05fd6c…` только для воспроизводимого сравнения и тестов миграции; в production он не импортируется.
