# Секретная сортировка

Авторская HTML5-головоломка на **Vite + TypeScript**. [Играть на DEV](https://artem917.github.io/secret-sort-dev/). ПК, мышь, клавиатура и мобильный touch; игра и рекорды сохраняются в текущем браузере. Backend, SDK, реклама, платежи и каталог Яндекс Игр не подключены.

## Правила нашей версии

- Ровно **10 колонок × 12 мест**, **9 видов × 12 фишек = 108**. Начальные высоты: `10,11,11,11,11,11,11,11,11,10`. Все занятые фишки закрыты; свободные позиции действительно пусты. Колонки выровнены снизу; верхняя фишка — первая занятая сверху.
- Нажатие на верхнюю закрытую `?` раскрывает только её, без переноса. Через другие фишки смотреть нельзя. Следующая закрытая фишка не раскрывается автоматически.
- Нажатие на k-ю фишку в верхней открытой непрерывной пачке одного вида выбирает ровно верхние k. Первая = одна, пятая = пять. Повторное нажатие того же размера или Esc снимает выбор; другой размер меняет его.
- Следующее нажатие выбирает принимающую колонку: пустую либо с таким же **открытым** верхним видом. Должна целиком помещаться выбранная группа до 12. На закрытую, другой вид или с переполнением — явный отказ. Автоматического слияния/удаления нет; направление выбирает игрок.
- **Резерв** — четыре отдельных места по одной открытой фишке независимо от вида. Группа в него не обрезается. Возврат на доску подчиняется обычным правилам. В настройках новых партий доступен контрольный режим **без резерва**.
- Победа: девять полностью открытых однородных колонок по 12, одна пустая, резерв пуст. Все 108 фишек сохраняются.
- Нет ограничения времени. «Ходов нет» появляется только при отсутствии раскрытия, переноса **и** доступной отмены. Ход из резерва тоже учитывается.

Резерв на четыре места, запрет переноса на другой вид, интерфейс, история, очки и подсказки — рабочие решения **нашей** версии. Ёмкость/полные правила оригинального физического хранилища и честная сложность при скрытой информации не доказаны. Видео не включено в сайт. Подробнее: [разбор референсов](docs/REFERENCE_REVIEW.md).

## Управление и сохранение

Нативные кнопки работают мышью, касанием, Enter/пробелом. Стрелки перемещают фокус по клеткам, Home/End — к краям колонки, Esc снимает выбор/закрывает окно, `U` или `Ctrl+Z` отменяют, `H` показывает подсказку. На узком телефоне поле прокручивается внутри своей панели; кнопки 1–10 переводят к нужной колонке. Резерв находится вне прокрутки поля.

Есть интерактивная тренировка: отдельное раскрытие, выбор 1/5 и настоящий перенос пяти через тот же движок. Настройки управляют реальными звуками Web Audio и короткими reveal/transfer-анимациями, учитывается системный reduced-motion. Пауза и уход в меню сохраняют позицию. При скрытии вкладки включается пауза.

**Отмена** восстанавливает предыдущее раскрытие или перенос, включая резерв. История ограничена 80 действиями и хранит компактные обратные операции. Переносы, отмены и подсказки считаются накопительно: отменённый перенос остаётся в счётчике. Это исключает фарм через undo. «Заново» в паузе повторяет тот же seed с нуля; «Новая партия» предлагает новый seed или позволяет ввести свой.

Схема localStorage версионирована: `secret-sort:game:v1`, `secret-sort:settings:v1`, `secret-sort:records:v1`. При загрузке проверяются инвентарь, ID, виды, открытость, вместимость, история и результат. Повреждённое/несовместимое сохранение не предлагается как «Продолжить». При отказе/quota storage игра остаётся доступной в текущей вкладке с предупреждением. После F5 сначала показывается меню; «Продолжить» есть только при незавершённой валидной партии.

## Генерация и seed

`ordered-donor-v1` — детерминированная конструкция из отсортированного состояния с точным начальным вектором высот. Генератор возвращает **сертификат из легальных раскрытий и переносов**. Перед началом каждой партии сертификат полностью проигрывается через production-движок с проверкой инвариантов. Непроверенная раскладка не допускается в игру.

Простой seed: **`onboarding`**. Для обычных партий: `certified-0`…`certified-999` или любая строка до 64 символов. Одинаковая нормализованная строка воспроизводит ту же раскладку в этой версии алгоритма. Можно открыть `?seed=certified-2`, затем «Играть», либо ввести seed в «Новая партия».

Проверено тестами: **1 000 различных раскладок, 2 000 полных replay** (каждая с резервом 0 и 4), **432 000 легальных действий** с инвентарём после каждого действия. Сертификаты содержат 108 раскрытий и 108 переносов. [Конструкция и доказательство](docs/GENERATION.md).

Сертификат знает будущие скрытые виды. Это доказательство существования решения из начального состояния, а не оптимальности, отсутствия тупиков после произвольных действий, разнообразия всех возможных раскладок или справедливой сложности для человека. Семейство намеренно конструктивное; обычные проверенные seed имеют девять смешанных колонок, onboarding — одну. Подсказки **не читают** скрытые виды или сертификат.

## Очки, рекорды и будущая реклама

При подтверждённой победе результат фиксируется один раз:

```text
max(0, 10000 - 30 * переносы - 250 * отмены - 500 * подсказки)
```

Раскрытие не приносит очков. Подсказка бесплатна для DEV и показывает **«Возможный ход»**, легальный по видимому состоянию; оптимальность не обещается. Сохраняются лучший счёт и минимум переносов с seed, а также число завершённых партий; повторная загрузка результата не добавляет победу. Рекорды локальны и не защищены от редактирования браузерного хранилища.

В `src/game/ad-reward-provider.ts` есть только будущий интерфейс `AdRewardProvider` для `hint`/`extra-undo`. Текущий provider `available: false`, всегда `rewarded: false`, UI его не вызывает. Реальных функций монетизации: **0**. Фиктивного просмотра рекламы нет.

## Разработка и проверки

Node.js 24 (от 24.13), npm:

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run dev
```

Dev: `http://127.0.0.1:5173/secret-sort-dev/`. Production preview: `npm run preview`, затем `http://127.0.0.1:4173/secret-sort-dev/`. В текущем наборе **44 модульных теста**, включая массовую сертификацию.

Браузерная проверка выполняется обычными кликами/тапами, без injection выигрышной позиции. При `?qa=1` доступен **только для чтения** `window.__secretSort.snapshot()` и `.certificate()`. В обычном режиме объект не создаётся. Диагностика не меняет правила, очки или сохранения.

Пример проверки через Playwright CLI (Node/npm должны быть доступны):

```sh
npx --yes --package @playwright/cli -- playwright-cli -s=secret-sort-qa open "http://127.0.0.1:4173/secret-sort-dev/?qa=1"
npx --yes --package @playwright/cli -- playwright-cli -s=secret-sort-qa run-code --filename=tests/browser-smoke.js
```

Для мобильного сценария сначала `goto` того же URL с `?qa=1&device=phone`, затем тот же `run-code`. Скрипт создаёт чистый browser context, проверяет тренировку, закрытые фишки, выбор, резерв, undo, F5/resume, hint, все 216 действий сертификата, натуральную пачку из пяти, победу, очки, рекорды, режим без резерва и ошибки ресурсов/консоли. Скриншоты — в `output/playwright/` (не часть production).

## Модули и публикация

```text
src/game/       # чистые правила, инвентарь, история, очки, сохранения, ad contract
src/generator/  # seed-конструкция и replay-верификатор
src/ui/         # DOM, ввод, адаптивный CSS и оригинальные SVG в public/
src/main.ts     # связывает движок, UI, storage и звук
tests/          # unit, генератор и браузерный acceptance-сценарий
```

Существующий `.github/workflows/deploy.yml` сохранён. Push в `main` запускает `npm ci`, TypeScript + production build и публикацию `dist` в GitHub Pages. Источник — GitHub Actions, `base: '/secret-sort-dev/'`. Тесты выполняются отдельной командой `npm test` перед push; workflow этой итерацией не менялся.

Девять SVG и `public/room.svg` написаны специально для игры; внешние шрифты, изображения стрима, бренды площадок и целые mockup PNG в сайт не включены. Физическое устройство Android/iOS, Safari и человеческая оценка интереса требуют отдельных проверок; эмуляция touch не считается проверкой реального телефона.
