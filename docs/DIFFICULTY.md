# Измеримое сравнение v0.2 / v0.3

Baseline: `e05fd6c0b56e9d6a8c12e05c5367b70dd3df1766`. Его четыре исходных модуля сохранены без изменений в `tests/fixtures/v02`. Команда `npm run compare:difficulty` сравнивает все 100 заранее заданных seed `comparison-0`…`comparison-99` и сохраняет все строки в `output/playwright/v03-difficulty.json`. Исключений по успешности/неуспешности стратегии нет.

Три варианта: исходный ordered-donor с ручным раскрытием; тот же старый старт/сертификат под новым автопоказом с пропуском уже открытых reveal; новый reverse-packets-v3. Смешанность измеряется по раскладке, метрики ходов — по полностью проверенному сертификату, не по предполагаемому оптимальному решению.

| Метрика | Old original | Old + autoReveal | New |
|---|---:|---:|---:|
| Смены вида между соседними фишками, среднее | 14.40 | 14.40 | 75.35 |
| Разных видов в колонке, среднее | 2.44 | 2.44 | 6.281 |
| Минимум видов в любой колонке | 1 | 1 | 5 |
| Максимальная одинаковая серия | 10–11 | 10–11 | 3 |
| Фишек в целиком однородных стартовых колонках | 10–11 | 10–11 | 0 |
| Максимум одного вида в колонке | 10–11 | 10–11 | 3–6 |
| Переносов в сертификате | 108 | 108 | 104–139 (среднее 117.07) |
| Групповых переносов, среднее | 9 | 9 | 83.56 |
| Самая длинная серия одиночных переносов | 28–42 | 28–42 | 5–9 |

| Легальных пар источник→цель по колонкам, среднее | 2.583 | 2.763 | 2.915 |
| Доля шагов с ≥2 легальными парами колонок | 100% | 100% | 69.7% |

Новый корпус более перемешан и значительно чаще переносит группы. Он не просто растягивает путь: сертификат обрывается при первой победе, финального перелистывания готовых стопок нет. Не каждая метрика возросла: шагов с несколькими колонками-альтернативами стало меньше. Законные альтернативы могут быть обратимыми или плохими, поэтому их число не доказывает количество хороших стратегий.

## Стратегия по видимой информации

Для проверки кроме сертификата используется отдельный тестовый игрок `tests/support/visible-policy.mjs`. На входе только открытые виды, флаги скрытости, длины и занятость резерва. Закрытые виды заменены на `-1`; ID, seed и сертификат отсутствуют. Он предпочитает освобождение новой скрытой фишки, возврат резерва, перенос в колонку, совпадение и большую группу. Гипотетический результат раскрытия до выбора не симулируется.

Ограниченная стратегия с фактическим Undo хранит до 79 родительских операций внутри истории 80. Это не исчерпывающий solver. В независимом исследовании 32 структур: простой вариант без резерва выиграл 7/32, с четырьмя местами — 32/32. Вариант с Undo выиграл 16/32 без резерва, остальные достигли лимита 2 000 действий. Резерв помог этой стратегии; сертификаты доказывают, что он не обязателен для решения.

Unit-тест проводит 12 обычных seed `mixed-v3-0`…`mixed-v3-11` через production-движок по новой наблюдаемой позиции после каждого реального действия, без подачи сертификата. Браузерный сценарий делает то же настоящими кликами и касаниями в трёх партиях:

| Seed | Стратегия: переносы | Групповые | Входы в резерв |
|---|---:|---:|---:|
| mixed-v3-0 | 104 | 76 | 1 |
| mixed-v3-4 | 105 | 69 | 4 |
| mixed-v3-11 | 105 | 84 | 2 |

В каждой дополнительно проверяются перенос+автопоказ, F5/resume, один Undo с восстановлением скрытости, выбор 1/5, запрет группы в резерв и победа. Поэтому итоговые игровые счётчики выше счётчиков чистой стратегии. Сертификат читается только после победы для подтверждения, что путь отличается. Скрипт и все ходы доступны в создаваемом JSON-отчёте.

Эти результаты доказывают работоспособность UI и прохождение по открытой информации. Они не заменяют человеческий плейтест и не доказывают, что игра достаточно трудна или интересна: проверенная стратегия с четырьмя местами справляется с этим семейством уверенно.
