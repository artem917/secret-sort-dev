# Сертификаты раскладок

Алгоритм: `ordered-donor-v1`, верх фишек — начало массива. Старт содержит 108 уникальных ID `kind * 12 + copy`, девять видов, по двенадцать каждого. Seed задаёт перестановку видов, порядок доноров, размеры и получателей обратных переносов. Нет поиска со случайным лимитом попыток и нет fallback на непроверенный shuffle.

## Почему достигаются точные высоты

1. Начинаем с девяти однородных колонок по 12 и пустой десятой. Целевые высоты: `[10,11,11,11,11,11,11,11,11,10]`.
2. Обрабатываем доноров 0…8 в seed-порядке. Получателями бывают только уже обработанные колонки и десятая. Поэтому новый донор до своего шага всё ещё содержит 12 одинаковых фишек.
3. Пусть `F` — суммарный дефицит высот обработанных колонок относительно цели; сначала `F=10`. Для донора `d=12-targetHeight`, то есть 1 или 2. Выбираем `r` в диапазоне `[d,F]`, распределяем r фишек только в свободные целевые места обработанных колонок. Донор сохраняет минимум две одинаковые фишки, так как `r<=10`.
4. До добавления донора дефицит уменьшается на r; новый донор добавляет дефицит `r-d`. Значит `F_new=F-d`. Сумма d по девяти донорам равна 10. После всех доноров F=0, то есть каждая колонка точно достигает целевой высоты, ни одна не переполнялась.

## Почему есть допустимый путь вперёд

Обратный перенос может положить вид на другой вид — это только **операция конструирования**, не разрешение игроку делать такой ход. При обратном проигрывании донора восстанавливается его однотипный остаток, поэтому возврат совпадающего вида на него допустим.

Для закрытого старта обратные пачки инвертируются **по одной фишке**, с отдельным reveal верхней скрытой фишки источника и, когда нужно, верхней скрытой фишки цели. Нельзя раскрывать фишку под открытой пачкой. Внутри одного вида порядок уникальных ID может измениться — правило требует сохранять ID, а не их исходный порядок.

После инверсии получаем однородные колонки, но ещё скрытые фишки. Для полного раскрытия вращаем каждую однородную колонку через текущую пустую: перенос открытого префикса, затем повторяем reveal + перенос одной. Девять колонок становятся полностью открытыми, одна остаётся пустой. Резерв не нужен, поэтому сертификат работает с его ёмкостью 0 и 4.

`verifyLevel()` независимо от внутренних helpers построителя проигрывает сертификат через реальные `createGame` / `applyAction`, после каждого действия вызывает `positionError` и требует реальную победу. Проверка вызывается перед каждой новой пользовательской партией. Тест с намеренно незаконным первым переносом подтверждает отказ verifier.

## Проверенная выборка

`npm test` проверяет **1 000 seed `certified-0`…`certified-999`**, их детерминизм и 1 000 различных последовательностей видов; каждую раскладку проигрывает с резервом 0 и 4. Это 2 000 завершённых replay и 432 000 действий, с проверкой ID, количества, видов, открытости и вместимости после каждого. Отдельно проверен простой `onboarding` в обоих режимах.

Минимальный набор 20 воспроизводимых seed:

```text
certified-0   certified-1   certified-2   certified-3   certified-4
certified-5   certified-6   certified-7   certified-8   certified-9
certified-10  certified-11  certified-12  certified-13  certified-14
certified-15  certified-16  certified-17  certified-18  certified-19
```

В `certified-2` действие сертификата с индексом 201 (нумерация с нуля) — перенос пяти из колонки 9 в колонку 8. Это натуральная достижимая позиция, используемая браузерным тестом для выбора и переноса группы из пяти.

## Ограничения доказательства

- Путь знает будущие скрытые виды. Честная сложность, интерес и оптимальная стратегия при неизвестных фишках не доказаны.
- Это конструктивное упорядоченное семейство, а не равномерная выборка всех возможных досок. В проверенных обычных партиях девять смешанных колонок, в onboarding — одна.
- Сертификат подтверждает решение **начальной** позиции. Произвольные действия игрока могут привести к тупику; доступны ограниченная отмена и повтор seed.
- 108 переносов сертификата не объявляются минимумом. Подсказка использует только видимое состояние и не обещает лучшего продолжения.
